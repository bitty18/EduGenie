1. Brainstorming & Ideation --- EduGenie

Project Title

**EduGenie --- Your AI Learning Assistant**

1. Background

Education has changed significantly over the last decade. Students use
textbooks, classroom lectures, internet resources, video tutorials and
conversational AI tools to clarify doubts.

General-purpose chat tools are not always convenient for learning. A
student who wants only a short explanation, a summary of lecture notes
or practice questions may need to repeatedly write detailed prompts.

EduGenie addresses this gap through a focused interface where each
common study activity has its own dedicated input box and button.

2. Problem Statement

Students commonly face three problems: 1. They encounter unfamiliar
concepts when an instructor is not immediately available. 2. Long and
unstructured notes are difficult to revise before examinations. 3.
Quick, topic-specific practice questions are not always available.

The project therefore aims to provide a simple, free-to-run web
application where students can ask questions, obtain explanations,
summarize notes and generate practice questions through one clean
interface.

3. Project Idea

EduGenie is a web-based learning assistant built with Python and
Streamlit. The planned intelligence layer is Google Gemini.

The four core learning activities are: - Ask a Question - Topic
Explainer - Notes Summarizer - Practice Question Generator

4. Main Objective

To provide a simple and interactive AI learning assistant that helps
students learn faster and revise more effectively.

5. Specific Objectives

-   Build a clean and easy-to-use Streamlit interface.
-   Allow students to ask academic questions.
-   Explain topics in simple, student-friendly language.
-   Convert long notes into short revision points.
-   Generate practice questions for a topic.
-   Validate empty input and provide friendly feedback.
-   Keep the code modular for future Gemini integration.
-   Host the source code on GitHub.





6. Target Users

-   School and college students
-   Examination-preparing students
-   Self-learners studying programming and technical subjects
-   Teachers who want quick practice questions

7. Expected Outcome

A focused learning interface that demonstrates the complete interaction
flow for asking questions, explaining topics, summarizing notes and
generating practice questions.
