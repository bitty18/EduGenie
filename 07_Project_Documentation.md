7. Project Documentation --- EduGenie

1. Abstract

EduGenie is a web-based learning assistant designed to help students
understand concepts, study topics, condense notes and practise with
questions.

The application uses Python and Streamlit. Google Gemini is the planned
AI layer. The current version is a working front-end prototype with
demonstration responses.

2. Project Conclusion

EduGenie brings four common study activities into one page: - Asking
questions - Understanding topics - Summarizing notes - Generating
practice questions

The current version demonstrates a validated interface, predictable
control flow and modular layout. The project documentation describes the
prototype honestly as a system whose responses are placeholders until
Gemini integration is added.

3. Results Achieved

-   Four planned features are present.
-   Input validation works.
-   The interface is visually consistent.
-   The code structure supports future AI integration.
-   The complete interaction flow is demonstrated.

4. Advantages

-   Simple to use
-   No prompt-writing skill required
-   Short and readable codebase
-   Browser-based interface
-   Uses Python and Streamlit
-   Modular design

5. Current Limitations

-   Responses are static demonstration text.
-   Gemini API is not yet connected.
-   The question module shows the same Java-inheritance answer.
-   No conversation history.
-   Results disappear after refresh.
-   No user login.
-   README is currently limited.
-   Repeated code blocks could be refactored.
