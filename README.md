# 🎓 EduGenie - AI Learning Assistant

EduGenie is a student-friendly learning assistant prototype built with Python and Streamlit.

## Features

- 💡 Ask Questions
- 📚 Explain Topics
- 📝 Summarize Notes
- 🧠 Generate Practice Questions

## Technologies

- Python
- Streamlit
- Google Gemini SDK
- GitHub

## Project Purpose

EduGenie helps students learn concepts, review notes, and practice questions through a simple learning interface.
